# Избранные дела kad.arbitr.ru

Программа для вашего компьютера: хранит избранные арбитражные (в первую очередь банкротные) дела,
подтягивает по ним данные через API и делает резервные копии. Работает в браузере, данные хранятся у вас.

## Mac — готовое приложение (Python не нужен)

Скачать:
- **Apple Silicon** (M1–M4, почти все Mac с 2021 года):
  https://github.com/Arthuralend/arbitr-pro/releases/latest/download/Arbitr-pro-mac-apple-silicon.dmg
- **Intel** (старые Mac):
  https://github.com/Arthuralend/arbitr-pro/releases/latest/download/Arbitr-pro-mac-intel.dmg

Свой процессор можно узнать так:  → «Об этом Mac», строка «Чип» или «Процессор».

Установка: откройте .dmg и перетащите Arbitr-pro в «Программы». Приложение не подписано
сертификатом Apple, поэтому при первом запуске macOS напишет, что не может проверить разработчика.
Нажмите «Готово», затем откройте «Системные настройки» → «Конфиденциальность и безопасность»,
внизу нажмите «Всё равно открыть». Это нужно сделать один раз.

Данные лежат в `~/Library/Application Support/Arbitr-pro`. Папку с резервными копиями можно
открыть кнопкой на вкладке «Резервные копии».

## Запуск из исходников (Windows, Linux, Mac)

1. Установите Python 3.9 или новее: https://www.python.org/downloads/
   (на Windows при установке отметьте галочку «Add Python to PATH»).
2. Распакуйте архив в любую папку.
3. Запустите:
   - Windows: двойной щелчок по `запустить.bat`;
   - macOS / Linux: `python3 app.py` в папке программы.
4. Откроется браузер на `http://127.0.0.1:8765`. Пока программа работает, не закрывайте чёрное окно.

Ничего дополнительно устанавливать не нужно: используется только стандартный Python.

## Первая настройка

В приложении для Mac по умолчанию выбран режим **kad.arbitr.ru напрямую**. Он работает без API и ключей:
программа сама открывает сайт в скрытом окне, как обычный браузер. Кнопка «Окно kad.arbitr.ru» показывает
это окно: в нём можно искать дела и добавлять их кнопкой «★ В избранное». Если сайт попросит проверку
«я не робот», окно откроется само. VPN лучше выключить, потому что из-за рубежа сайт не отвечает (код 451).

Другие источники (⚙ → **Источник данных**):
- **api-cloud.ru**: токен из личного кабинета (32 символа). Запрос по делу стоит около 0,5 ₽.
- **api-assist.com**: ключ доступа.
- **Демо**: тестовые данные без интернета, чтобы попробовать программу.

## Что умеет

- **Добавить дело**: по номеру (`А40-123456/2024`, латинская «A» тоже подойдёт) или по ссылке
  `kad.arbitr.ru/Card/…`. Можно вставить сразу целый список. Повторно одно и то же дело не добавится.
- **Названия**: подставляются автоматически из дела («Банкротство: ООО «Ромашка»» или «Истец — Ответчик»).
  Своё название сохраняется, а к автоматическому можно вернуться одной кнопкой.
- **Метки, заметки, закрепление ★, архив, поиск, фильтры, сортировка.**
- **Стадия банкротства** определяется автоматически по судебным актам (наблюдение, конкурсное производство,
  реструктуризация, реализация имущества…). Её можно задать вручную.
- **Отслеживание изменений**: «⟳ Обновить все» запрашивает свежие данные и отмечает новые документы.
  Все находки собираются во вкладке «Лента изменений».
- **Заседания**: список ближайших заседаний и выгрузка в календарь (.ics) с напоминанием за сутки.
- **Поиск дел по участнику** (ИНН или название) с фильтром «только банкротные» и кнопкой «В избранное».
- **Ссылки**: на карточку дела в КАД и на должника в Федресурсе (ЕФРСБ).
- **Резервные копии**:
  - полная копия в .json (дела, названия, метки, заметки; ключи API в неё не попадают);
  - таблица для Excel (.csv) и список номеров (.txt);
  - восстановление из файла: объединить с текущим избранным или заменить его;
  - автоматическая копия раз в день в `data/backups` (хранятся последние 30).
- Горячие клавиши: `/` — поиск, `N` — добавить, `Esc` — закрыть карточку.

## Профили

Все данные лежат в папке `data` рядом с программой. Если нужен отдельный профиль, например для другого
клиента, запустите `python app.py --data папка_профиля`. Чтобы перенести избранное на другой компьютер,
скопируйте папку `data` или используйте резервную копию .json.

## Сборка новой версии для Mac

Приложение собирает GitHub Actions (`.github/workflows/build-mac.yml`) при каждом изменении в ветке
`main`, а также вручную: Actions → «Сборка для Mac» → Run workflow. Через 5–10 минут новая версия
появляется в Releases, и ссылки выше автоматически ведут на неё.
